# Event planning checklist

The event directory reads this file (`scripts/event-directory/event_directory.py`). Edit the tags here; keep the format `* Item — CODE, CODE`.

## Event type codes

* ALL = applies to almost every event type
* CONF = conference, summit, convention, seminar
* EXPO = trade show, expo, exhibition
* LAUNCH = product launch, press event, brand activation
* FEST = festival, concert, outdoor event
* WED = wedding, private party, celebration
* GALA = gala, awards, fundraiser
* CORP = corporate meeting, workshop, retreat, offsite
* SPORT = sports event, tournament, race
* HYBRID = virtual, hybrid, livestream-first
* RETAIL = pop-up, retail, showroom, sampling
* ROAD = roadshow, multi-city tour
* NET = networking, social, mixer

How to filter: keep rows tagged ALL or any of the event's codes. A wedding keeps ALL or WED; a conference keeps ALL or CONF; a hybrid launch keeps ALL, LAUNCH or HYBRID.
