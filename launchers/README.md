# Launchers

Double-click **Maataa.command** in the brahmini folder for a menu of everything here. Each script also works on its own.

| Script | What it does |
| --- | --- |
| Maataa - Start coding | Starts Ollama and Maataa, makes sure a coding model is installed, approves ~/Maataa Projects, offers the coding checks |
| Build NOVA app | Runs the tests and packs Maataa Workstation.app, the .dmg and the portable folder into nova-console/packaging/dist |
| Install Maataa app | Puts the newest built app into /Applications. An older copy goes to the Trash after you agree |
| Check NOVA on this Mac | Runs every media feature once and writes a report |
| Install ComfyUI for NOVA · Start ComfyUI for NOVA | The image engine, about 13 GB |
| Add upscale model · Add tensor view · Add audio models · Add ACE-Step 1.5 · Add Wan video models | ComfyUI add-ons and models |
| Install Kokoro voices for NOVA · Add multilingual speech model · Install LTX-2 video for NOVA | Voices, speech-to-text, video with sound |
| AAI - Set up | The Vidyut derivation engine for Maataa AAI |
| Guru 0–6 | Guru: fix PyTorch, set up, corpus, train, talk, add to Ollama, look up a sutra. Corpus and Train are blocked by the current I7 gate |
| Build / Rebuild event directory · Fill event directory gaps from Google · Build event map | The Brahmini Knowledge Collector's event directory |
| Compare song engines · Rename local model to guru-maataa · Push to GitHub | Utilities |

Most installers can also be started from the **Install** page inside Maataa, which shows sizes, free space and what is already installed.
